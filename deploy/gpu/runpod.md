# RunPod serverless template

This is documentation only. It does not rent a GPU.

Use a scale-to-zero serverless endpoint and set `TENSOR_PARALLEL_SIZE` in the endpoint environment. Leave `GPU_MONTHLY_CAP_USD` at 0 until a spend cap is chosen. Put `GPU_NODE_URL` and `GPU_NODE_KEY` in the server environment, not in this file and not in the browser.
