Add Valhalla to Chrome

Chrome does not let a website install an extension by itself. After review, Add to Chrome will open the Chrome Web Store. Until then, use these three steps on a computer. Chrome on Android cannot install extensions.

1. Open the extensions page

Type chrome://extensions in the address bar.

2. Turn on Developer mode

Use the switch on that page.

3. Load the folder

Unzip the release file, then choose Load unpacked and select that folder. The extension is read-only. It cannot send or withdraw.
