The downloadable ICS at `/valos/milestones.ics` carries these stable IDs as VTODO UIDs and links each item to [PR #54](https://github.com/TokenJunction/eliza-valhalla/pull/54) and the [ValOS page](https://valhalla-app.xyz/valos/). Its `DTSTAMP` is file metadata only. These are undated calendar tasks, not Google Calendar events. Actual calendar events require owner-approved dates, times, and a target calendar. Calendar synchronization is not implemented.

No matching dates, event times, or target calendar are known. Do not infer event timing from the current date or create Google Calendar entries without owner approval.
